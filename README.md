# Ashhad & Lubna's Cinematic walima

Build an award-winning, cinematic, immersive digital wedding invitation website for the walima celebration of Mohammed Ashhad & Lubna Fathima.

This must NOT look like a normal wedding website.

Do NOT create a collection of cards stacked vertically.

Create an emotional visual journey where scrolling feels like watching a beautifully directed wedding film.

Think:

Luxury Islamic editorial + cinematic film + immersive storytelling + interactive invitation + modern 3D web experience.

The goal is for someone opening this link on WhatsApp to immediately think:

“I have never seen a wedding invitation like this.”



CORE STORY

The Nikah has already happened.

Nikah:

12 December 2026

The website is NOT inviting guests to the Nikah.

The website is inviting guests to the:

walima

walima:

13 December 2026
7:30 PM

Venue:

Royal Orchid Grand Ballroom
Airport Road, Bengaluru, Karnataka

The entire experience should tell this story:

Two people → Nikah → New chapter → Celebration → walima invitation

CINEMATIC CAMERA SYSTEM

Implement a pseudo-camera system throughout the page.

As the user scrolls:

zoom in

zoom out

pan horizontally

rotate subtle elements

shift depth

blur/unblur

scale typography

reveal masks

The user should feel like the page has a camera moving through a story.

Use:

Framer Motion / Motion
GSAP if necessary
Three.js only where it genuinely improves the experience

Do NOT add WebGL simply for the sake of saying it uses 3D.



3D INVITATION EFFECT

For the opening scene, create a subtle interactive 3D invitation/card.

It should have:

depth

gold edges

soft shadow

slight mouse movement on desktop

gyroscope-like movement on mobile if practical

When the user scrolls:

the invitation opens / transitions into the website.

This should be elegant, not gimmicky.



PARTICLE SYSTEM

Create a subtle atmospheric particle system.

Particles should:

float slowly

vary in opacity

react slightly to cursor movement

disappear/reappear naturally

Use very few particles on mobile.

Performance is extremely important.

MOBILE EXPERIENCE

This is extremely important.

The website will primarily be opened from WhatsApp on phones.

Do NOT simply shrink the desktop version.

Create a dedicated mobile composition.

On mobile:

maintain cinematic transitions

keep typography dramatic

use touch-friendly controls

avoid long loading times

preserve visual storytelling

The experience should still feel extraordinary on a normal iPhone/Android device.
